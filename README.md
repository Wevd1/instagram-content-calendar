# Instagram Content Calendar

Repositório de apoio para o agendamento automático de posts no Instagram (@duartelabs).

- `calendar.json` — lista de posts programados (data, legenda, imagem, status)
- `images/` — artes finais publicadas (hospedagem permanente via GitHub raw URLs)

Uma rotina agendada na nuvem verifica este calendário diariamente e publica os posts programados para o dia.
